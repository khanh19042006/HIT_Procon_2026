# Templates cho comment hàm

Thư mục này chứa template comment chuẩn để dùng cho các hàm trong project.

## Cách dùng

- Sao chép đoạn comment mẫu từ file `function_comment_template.hpp`
- Thay các phần trong ngoặc vuông bằng nội dung thực tế
- Giữ nguyên phong cách tiếng Việt có dấu, rõ ràng và ngắn gọn

## Mẫu chuẩn

```cpp
/**
 * @brief [Mô tả ngắn gọn chức năng của hàm]
 *
 * Mục đích:
 * - [Mô tả mục tiêu chính của hàm]
 * - [Mô tả tác dụng phụ, nếu có]
 *
 * Đầu vào:
 * @param [tên tham số] [Mô tả ý nghĩa của tham số]
 *
 * Đầu ra:
 * @return [Mô tả giá trị trả về]
 *
 * Thuật toán / logic:
 * - [Bước 1]
 * - [Bước 2]
 *
 * Giới hạn:
 * - [Giới hạn 1]
 * - [Giới hạn 2]
 */
```
